## 接続先の管理

ホームのボタン、またはVoyagerに割り当てたF21/F22/F23でSlot 1/2/3へ切り替えます。
表示名はMac mini / Linux / MacBook Airです。切替時は旧PCへの入力を全解放し、
キー・Consumer/System入力・マウスボタンが解放されてから新PCへ入力を送ります。
接続先が起動していなくても別のSlotへ切り替えられます。

「設定」→「接続先の管理」で新規登録、ペアリング受付の中止、登録解除を操作します。
ペアリング受付は既定60秒。登録済みPCの再接続は自動で行います。
PC交換は確認付きの登録解除が成功した後にペアリングを開始してください。
解除対象以外のSlotは保持します。PC側にも古い登録が残る場合は、その登録を削除します。

## Navigatorの操作

| 操作 | 動作 |
|---|---|
| 1本指を動かす | ポインタ移動 |
| 1本指タップ | 左クリック |
| 2本指タップ | 右クリック |
| 3本指タップ | 中クリック |
| 2本指で動かす | スクロール |
| 2本指で素早く横に払う | ブラウザの戻る／進む（macOSのCmd+[ / Cmd+]、US配列前提） |
| 同じ場所で2回タップ | ダブルクリック |

ドラッグは、タップ後200ms以内に前のタップ位置から4mm以内へ1本指を戻して動かすと始まります。
開始後は、どこで指を離しても左ボタンを保持し、次のタッチで続行します。保持に時間上限はありません。
着地時にポインタが飛ばないよう基準を取り直します。

**ドラッグを終えるには、短く・動かさずにタップします。** この操作では追加クリックを送りません。
動かない長いタッチの後に指を離した場合や、ジェスチャー状態のResetでも解放します。
物理ボタンによるドラッグはこのドラッグロックの対象外です。

設定値は[開発ガイド](development.md#ジェスチャー設定)を参照してください。
長文選択の使い勝手と誤開始の頻度は調整中です。ブラウザ履歴ショートカットはOSごとの切替を実装していません。

## 消灯・休止

- LCD操作や表示を起こす通知から30秒で減光する。
- キーボード・タッチパッド操作もなく5分経つとLCDバックライトと本体LEDを消す。USB/BLEは継続する。
- 入力すると画面は減光状態で復帰し、入力をPCへ送る。LCDの最初のタップは復帰のみ。
- 「設定」→「休止」を3秒以内にもう一度タップすると本体をDeep-sleepにする。
  休止時は入力を解放し、BLE/Wi-Fiを停止する。画面タップで再起動し、前回の給電方式を再開する。

休止は登録情報を削除しません。内部昇圧モードだけVoyagerへの給電を止め、外部給電時はVBUSを操作しません。
サーボ電源は変更しません。休止の基本動作と消灯は実機で確認済みです。
給電方式別の挙動・復帰時間・消費電流の測定は未完了です。

## LEDとLCD

選択先の色はMac mini=青、Linux=緑、MacBook Air=白です。
正常時は左右ともその色で点灯し、BLE未接続時は点滅します。

| 表示 | 意味 |
|---|---|
| 左が赤 | キーボード未検出、USB開始失敗、選択先のBLE管理エラー |
| 右が赤 | 外部給電も充電も検出していない状態 |
| 消灯 | 消灯待機または休止 |

赤は点滅しません。詳細はLCDの表示を確認してください。電池残量が取得できないときは不明扱いです。
LEDの各状態表示の実機確認は未完了です。
